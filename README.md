# Онлайн-магазин
Платформа для онлайн-магазину з доставкою
## Мета
Забезпечити повний життєвий цикл онлайн-покупки: від перегляду товарів до оформлення замовлення
## Основні сутності й процеси 
Клієнт має змогу переглядати товари, додавати його в кошик та видаляти з нього, та власне замовляти його й оплачувати покупку 
Менеджери сайту можуть змінювати категорії, додавати чи редагувати дані про товар 
Клієнт може зв'язатися з підтримкою(менеджером) в спеціальному чаті 
Товар приходить на вказану клієнтом адресу з допомогою поштових служб
